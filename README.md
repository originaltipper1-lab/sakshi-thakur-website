# Sakshi Thakur — Official Channel

A responsive Telegram landing page based on the supplied design, featuring an animated gradient card, particle background, circular countdown, and direct join button. Visitors automatically open the supplied Telegram invite after ten seconds.

Built with static HTML, CSS, and JavaScript. No packages, build step, database, or server functions are required. Google Fonts supplies Plus Jakarta Sans; icons are inline SVGs.

For local development, serve this directory with any static HTTP server, or use `netlify dev --port 8889`. Netlify publishes the root directory using `netlify.toml`.

Edit `index.html` for page content, `styles.css` for presentation, and `script.js` for countdown behavior. Keep the invite URL in the HTML button and JavaScript redirect consistent. Reduced-motion preferences disable decorative animations, and browser zoom remains enabled.
