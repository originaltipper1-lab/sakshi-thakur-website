# Project guide

This is a complete static landing page for Sakshi Thakur's Telegram channel. Preserve the supplied neon glass card design and ten-second automatic redirect.

- `index.html`: semantic page structure, metadata, inline SVG icons, and direct Telegram link.
- `styles.css`: responsive layout, animated gradient border, ambient glow, countdown, button states, and reduced-motion rules.
- `script.js`: deadline-based countdown and decorative canvas particles. The direct link works without JavaScript.
- `netlify.toml`: publishes the repository root with no build step.

Use plain browser APIs and no framework or dependency installation. Keep HTML and JavaScript invite URLs synchronized. Preserve keyboard focus, zoom support, narrow-screen layout, and reduced-motion handling. No persistence is needed.
